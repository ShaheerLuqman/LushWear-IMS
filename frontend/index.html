Create Cashbook Entry

Debit (Received)
Credit (Paid)
 

One entry per line. Format: <KIND>: <AMOUNT> <LEDGER> [(<PARTICULARS>)]

  • From / Cr — credits the LEDGER, so cash is received. e.g. From: 2064 TCS (Received order payment)
  • To / Dr — debits the LEDGER, so cash is paid. e.g. To: 2064 Meezan Bank (Received order payment)

Particulars are optional — omit them and a default description is generated.

Order advance shorthand — use Order# in place of a ledger name to post straight to the Orders ledger:

From: 3500 Order# 11473
To: 3500 Meezan Bank
